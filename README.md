# renOunce: Ren'Py 8.4.1

Ren'Py 8.4.1/Python 3.12 engine for Nintendo Switch 2 homebrew.

Run `build-renpy84-ci.bash` in the devkitpro container to compile the
engine, then `package-renpy84-release.bash` to create the game-free NRO and
SHA-256 file. The `8.4.1` branch builds and publishes those files as a
GitHub release on each push.

See [release notes](releases/renpy-8.4.1.md) and [port notes](RENPY8-PORT.md).
